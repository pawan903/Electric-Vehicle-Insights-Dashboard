# Electric Vehicle Insights Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze Electric Vehicle (EV) population data.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* Excel / CSV
* Data Visualization

## Project Objectives

* Analyze electric vehicle adoption.
* Understand EV distribution by location.
* Analyze vehicle manufacturers and models.
* Identify important trends and patterns in EV data.
* Present insights through an interactive Power BI dashboard.

## Dataset

The project uses the Electric Vehicle Population dataset.

## Project Files

* `power bi project.pbix` – Power BI dashboard file
* `Electric_Vehicle_Population_Data.zip` – Compressed EV dataset
* `compressed_Car Sales.xlsx` – Additional dataset file

## Dashboard Features

* EV population analysis
* Location-wise EV analysis
* Manufacturer analysis
* Model analysis
* Interactive filters and visualizations
